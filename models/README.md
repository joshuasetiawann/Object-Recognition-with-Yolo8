# Models

Place your YOLOv8 weight files (`.pt`) in this directory.

Pretrained weights such as `yolov8n.pt` are downloaded automatically by
Ultralytics on first use. Custom-trained weights produced by `src/train.py`
are saved under `runs/detect/train/weights/best.pt` — copy the ones you want
to keep here.

> Note: `.pt` files are ignored by git (see `.gitignore`) to keep the
> repository lightweight.
